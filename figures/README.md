# Thư mục hình ảnh

- `generated/`: hình sơ đồ, đồ thị hoặc ảnh kỹ thuật do nhóm tự dựng/xuất từ STM32CubeMX và công cụ đo.
- `screenshots/`: ảnh nghiệm thu theo đúng tên file trong `chapters/07-photo-script.tex`.

Ảnh chụp board nên đủ sáng, không lóa LCD, thấy rõ dây nối và toàn bộ phần cứng. Ảnh chụp màn hình nên cắt gọn, không để lộ thông tin cá nhân. Khuyến nghị PNG cho ảnh giao diện/công cụ và JPG chất lượng cao cho ảnh chụp phần cứng; chiều rộng tối thiểu 1600 px.
